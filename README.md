# AIPenPilot

AIPenPilot is an AI-powered blog post generator that helps content creators and marketers produce high-quality blog content with minimal effort. The platform uses advanced AI to research, write, and optimize blog posts that can be published directly to WordPress sites.

## Features

- **AI-Powered Content Generation**: Create blog posts on any topic with customizable tone and length
- **WordPress Integration**: Publish directly to your WordPress sites
- **Content Management**: Organize, edit, and track all your generated content
- **Analytics Dashboard**: Monitor content performance and usage statistics
- **Subscription Plans**: Free, Basic, and Premium tiers with different feature sets

## Tech Stack

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: FastAPI, Python, Autogen
- **Database**: PostgreSQL (Neon)
- **Authentication**: NextAuth.js with Google OAuth and credentials
- **Payments**: Stripe subscription management
- **Deployment**: Docker containerization

## Docker Setup

This project uses Docker for containerization and supports multiple environments (development, staging, production).
